# SEO launch guide — More Than a Kiosk

## Production URL
`https://morethanakiosk.com/`

The HTML metadata, canonical URLs, Open Graph previews, Twitter previews, LocalBusiness structured data, `robots.txt`, `sitemap.xml`, manifest and GitHub Pages `CNAME` are already configured for this address.

## Required deployment steps

1. In the DNS provider for `morethanakiosk.com`, configure the apex-domain records required by your hosting provider.
2. In the GitHub repository, open **Settings → Pages** and set the custom domain to `morethanakiosk.com`.
3. Enable **Enforce HTTPS** after the certificate becomes available.
4. Open Google Search Console and add a **Domain property** for `morethanakiosk.com`, or a **URL-prefix property** for `https://morethanakiosk.com/`.
5. Verification options:
   - For the URL-prefix property, the Google HTML verification file and verification meta tag are included in this project. Deploy the site, open the verification-file URL, then click **Verify** in Search Console.
   - For the Domain property, use the unique DNS TXT record generated by Google; website files and meta tags cannot verify a Domain property.
6. Submit this sitemap in Search Console:
   `https://morethanakiosk.com/sitemap.xml`
7. Inspect `https://morethanakiosk.com/` and click **Request indexing**.
8. In the verified Google Business Profile, add `https://morethanakiosk.com/` as the website and `https://morethanakiosk.com/menu.html` as the menu link.
